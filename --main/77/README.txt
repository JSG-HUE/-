========================================================
  中国战场 · 1927—1949
  2D 横版历史题材射击游戏
========================================================

【怎么玩】
1. 双击本文件夹里的 index.html，推荐 Edge / Chrome。
2. 也可以双击“启动游戏.bat”，用默认浏览器打开。
3. 游戏默认进入“战役地图”，地图就是主菜单。
   上方可以调整战斗难度，也可以打开“战地日志”和“操作说明”。
   选年代：
     抗日战争 1937—1945
     土地革命 1927—1936
     解放战争 1946—1949
4. 再点地图上的红色标记，右侧查看日期、地点、部队、任务、关键人物，
   点击“进入战役”。
5. 左侧任务栏会一直显示当前任务、子目标、关键人物、生命与弹药。
6. 游戏中按 Esc 暂停；暂停、失败或章节结算里的“返回主菜单”会回到地图。

无需安装、无需联网、无需服务器；所有场景、人物肖像、音效都由代码生成。

【操作】
  A / D 或 ← / →     左右移动
  鼠标                 瞄准
  鼠标左键             射击
  鼠标右键 / F         大刀
  R                    装填
  Space / W            跳跃
  Ctrl / S            蹲下
  Shift                冲刺
  E                    补给 / 升旗 / 封锁 / 撤离
  Esc                  暂停 / 返回
  M                    静音

【右下角摄像头 / 手势】
进入战役后，战场右下角会出现摄像头窗口，下方有两个开关：

  摄像头：开启/关闭摄像头，首次开启需要浏览器允许摄像头权限。
  手势：开启/关闭手势操控；开启手势时会自动请求摄像头。

手势操控（画面为镜像，按画面方向描述）：
  手在画面左侧       向左移动
  手在画面右侧       向右移动
  手向上抬           跳跃
  手向下压           蹲下
  鼠标瞄准、左键射击、键盘移动始终可用，手势只是额外叠加。

摄像头画面只在本地浏览器中处理，不会上传。游戏默认不开启摄像头，
离开战场返回战役地图时会自动关闭摄像头。若浏览器拒绝权限，请在地址栏
允许摄像头；如果直接双击 index.html 时浏览器限制 file:// 摄像头，
双击“启动摄像头版.bat”：

  它会在 127.0.0.1 上启动一个只在本机运行的小型网页服务，并自动打开
  http://127.0.0.1:8765/index.html。这个地址属于安全上下文，摄像头
  权限可以正常使用。关闭黑色命令行窗口即可停止服务。

【特殊战役：西安事变】
西安事变不是射击关，而是一个“封锁与谈判”的历史场景。你扮演东北军
卫队营士兵小关，任务是不开枪、控制华清池外围、封锁五间厅、等待谈判
结果。走到标记点按 E 完成封锁。枪在肩上，但今晚的任务是停止内战。

【历史说明】
1927年8月1日，周恩来、贺龙、叶挺、朱德、刘伯承等领导南昌起义，
打响了武装反抗国民党反动派的第一枪。此后，红军在井冈山、中央苏区
等地与国民党军作战，并在长征中飞夺泸定桥。

1936年12月12日，张学良、杨虎城在西安华清池发动兵谏，逼蒋介石停止
内战、一致抗日。经中共代表周恩来等斡旋，西安事变和平解决，促成第二
次国共合作，抗日民族统一战线初步形成。

1937年7月7日夜，日军在北平西南卢沟桥附近演习，借口士兵失踪要求进入
宛平县城搜查，遭中国守军拒绝。7月8日拂晓，日军炮轰宛平城、进攻卢沟桥，
中国守军奋起抵抗，七七事变爆发，全民族抗战由此开始。

抗战期间，中国军队在正面战场与敌后战场共同抗击日军。平型关、台儿庄、
万家岭、四行仓库、长沙、百团大战、常德、衡阳、松山等战役，都是这段
历史的不同侧面。

1946—1949年的解放战争是国共两党之间的内战。孟良崮、塔山等战役
是其中的重要战斗。

游戏中的小满、栓柱、大河、秋生、铁柱、石头、阿昌、小豹、南生、湘生、
阿贵、小钟、小龙、小虎、小关、小鲁、小东都是虚构的普通士兵；真实历史
人物的职务、战役时间与部队番号依据公开史料。对白和战斗细节为艺术化
处理，不作为史料引用。地图为历史示意图，边界与地名仅作叙事定位。

本作没有血腥表现。谨以此纪念在战争中牺牲的普通人。
铭记历史，珍爱和平。

【战斗提示】
· 沙袋、木箱、断墙和山石都能挡住子弹。蹲在掩体后更安全。
· 汉阳造是栓动步枪，每发之间需要拉栓；弹仓打空会自动装填。
· 近距离用大刀更有效；攻坚战役中大刀范围更大。
· 击倒敌人有概率掉落弹药袋，走近自动拾取。
· 每场战役出生点附近有一个补给箱，可以补充一次体力和弹药。
· 敌人头顶的红色小三角是敌军识别标记。
· 生命值在脱离战斗一段时间后会缓慢恢复。

【难度】
  新兵：敌军火力较弱，体力上限更高，初始弹药更多。
  老兵：标准战场体验。
  血战：敌军更准、更疼、更快，体力上限更低。

【存档】
卢沟桥主线的章节进度保存在浏览器本地（localStorage）。
战役地图的完成进度单独保存；完成一场独立战役后，地图标记会显示“已完成”。
“从第一章重新开始”只清除卢沟桥主线进度，不会清除地图完成记录。

# 方块旷野

一个可在桌面浏览器中游玩的第一人称 3D 方块沙盒原型，使用 Three.js 渲染，无需安装或构建步骤。

## 启动

直接用浏览器打开项目根目录的 `index.html`。页面需要联网加载 Three.js CDN。

## 操作

- `W` `A` `S` `D` 移动，`Shift` 加速，`空格` 跳跃
- 鼠标移动调整视角，`ESC` 暂停或释放鼠标（直接打开文件时鼠标不会被锁定）
- 鼠标左键挖掘，右键放置方块
- `1` 至 `6` 或点击快捷栏选择方块
- 点击“重新生成世界”恢复地形

游戏包含程序生成的丘陵地形、树木、碰撞、重力和六种可用方块。当前版本是单页原型，不包含存档、多人联机或 Windows 安装程序。

【怎么玩】
1. 双击本文件夹里的 index.html，推荐 Edge / Chrome。
2. 也可以双击“启动游戏.bat”，用默认浏览器打开。
3. 游戏默认进入“战役地图”，地图就是主菜单。
   上方可以调整战斗难度，也可以打开“战地日志”和“操作说明”。
   选年代：
     抗日战争 1937—1945
     土地革命 1927—1936
     解放战争 1946—1949
4. 再点地图上的红色标记，右侧查看日期、地点、部队、任务、关键人物，
   点击“进入战役”。
5. 战斗画面为 3D 低多边形第一人称视角：镜头就是本场战役小兵的眼睛，
   桥面、铁路、村镇、山地和士兵都是完整 3D 场景；W/S 前进后退、A/D 左右横移，
   可以绕开沙袋和箱子。点击画面锁定鼠标后，鼠标控制视角和瞄准，
   左键沿准星射击，Space 跳跃、C/Ctrl 蹲下。
6. 左侧任务栏会一直显示当前任务、子目标、关键人物、生命与弹药。
7. 游戏中按 Esc 暂停；暂停、失败或章节结算里的“返回主菜单”会回到地图。

【3D 竖切 · 卢沟桥】
地图右上角新增了“3D 竖切”按钮。这是一个独立的技术验证场景：

- 真正的 3D 坐标，不再是 2D 横版坐标换算
- 玩家胶囊体与桥栏、沙袋、木箱做碰撞
- 鼠标锁定后控制视角和瞄准，水平视角可 360° 旋转；Q/E 也能转身
- 左键从准星方向打 3D 射线
- 三名敌人使用网格 A* 寻路，会绕过沙袋和木箱
- 场景扩展到卢沟桥、永定河、宛平城门、城墙、河岸民居、树林、远山和 29 军阵地
- 增加月光、火光、雨、中国守军和日军红色识别标记
- 视野范围扩大到 380，雾距拉远，敌人放在更靠前的位置，开局就能看见
- 按 Esc 暂停，右上角可以退出返回战役地图

这个竖切暂未替换 17 场正式战役，只是先把“真 3D 移动 + 碰撞 + 鼠标 + 寻路 + 射击”跑通。

无需安装、无需联网、无需服务器；所有场景、人物肖像、音效都由代码生成。
3D 画面需要浏览器支持 WebGL；如果显卡/浏览器不支持，会自动退回原来的
2D 画面，战役流程不受影响。

【操作】
  W / S 或 ↑ / ↓      前后移动
  A / D 或 ← / →      左右横移
  Q / E                转身（360°）
  鼠标                 锁定后控制视角和瞄准
  鼠标左键             沿准星射击
  鼠标右键 / F         大刀
  R                    装填
  Space                跳跃
  C / Ctrl             蹲下
  Shift                冲刺
  E                    补给 / 升旗 / 封锁 / 撤离
  Esc                  暂停 / 返回
  M                    静音

进入战斗后先点击一次画面锁定鼠标；锁定后准星在屏幕中央，移动鼠标转头，
左键从准星方向射击。按 Esc 会解锁鼠标并暂停。如果浏览器拒绝鼠标锁定，
游戏会自动切换成直接鼠标视角：移动鼠标同样能转视角和瞄准，不需要锁定。

人物和物品都带有碰撞箱：敌人、友军、平民会沿街推进并绕开沙袋、箱子、
残墙等障碍；准星射击使用 3D 碰撞箱判定，不会穿过人体模型。

【历史说明】
1927年8月1日，周恩来、贺龙、叶挺、朱德、刘伯承等领导南昌起义，
打响了武装反抗国民党反动派的第一枪。此后，红军在井冈山、中央苏区
等地与国民党军作战，并在长征中飞夺泸定桥。

1936年12月12日，张学良、杨虎城在西安华清池发动兵谏，逼蒋介石停止
内战、一致抗日。经中共代表周恩来等斡旋，西安事变和平解决，促成第二
次国共合作，抗日民族统一战线初步形成。

1937年7月7日夜，日军在北平西南卢沟桥附近演习，借口士兵失踪要求进入
宛平县城搜查，遭中国守军拒绝。7月8日拂晓，日军炮轰宛平城、进攻卢沟桥，
中国守军奋起抵抗，七七事变爆发，全民族抗战由此开始。

抗战期间，中国军队在正面战场与敌后战场共同抗击日军。平型关、台儿庄、
万家岭、四行仓库、长沙、百团大战、常德、衡阳、松山等战役，都是这段
历史的不同侧面。

1946—1949年的解放战争是国共两党之间的内战。孟良崮、塔山等战役
是其中的重要战斗。

游戏中的小满、栓柱、大河、秋生、铁柱、石头、阿昌、小豹、南生、湘生、
阿贵、小钟、小龙、小虎、小关、小鲁、小东都是虚构的普通士兵；真实历史
人物的职务、战役时间与部队番号依据公开史料。对白和战斗细节为艺术化
处理，不作为史料引用。地图为历史示意图，边界与地名仅作叙事定位。

本作没有血腥表现。谨以此纪念在战争中牺牲的普通人。
铭记历史，珍爱和平。

【战斗提示】
· 沙袋、木箱、断墙和山石都能挡住子弹。蹲在掩体后更安全。
· 汉阳造是栓动步枪，每发之间需要拉栓；弹仓打空会自动装填。
· 近距离用大刀更有效；攻坚战役中大刀范围更大。
· 击倒敌人有概率掉落弹药袋，走近自动拾取。
· 每场战役出生点附近有一个补给箱，可以补充一次体力和弹药。
· 敌人头顶的红色小三角是敌军识别标记。
· 生命值在脱离战斗一段时间后会缓慢恢复。

【难度】
  新兵：敌军火力较弱，体力上限更高，初始弹药更多。
  老兵：标准战场体验。
  血战：敌军更准、更疼、更快，体力上限更低。

【怎么玩】
1. 双击本文件夹里的 index.html，推荐 Edge / Chrome。
2. 也可以双击“启动游戏.bat”，用默认浏览器打开。
3. 在标题画面选择难度、章节，点击“开始 · 第一章”。
4. 左侧任务栏会一直显示当前任务、子目标、关键人物、生命与弹药。
5. 按 Esc 暂停。

无需安装、无需联网、无需服务器；所有场景、人物肖像、音效都由代码生成。

【操作】
  A / D 或 ← / →     左右移动
  鼠标                 瞄准
  鼠标左键             射击
  鼠标右键 / F         大刀
  R                    装填
  Space / W            跳跃
  Ctrl / S             蹲下
  Shift                冲刺
  E                    补给 / 升旗 / 撤离
  Esc                  暂停
  M                    静音

【三个章节】
第一章  卢沟桥 · 夜        1937.7.7 — 7.8
  日军借口演习中一名士兵失踪，要求进入宛平县城搜查，被中国守军拒绝。
  拂晓，日军炮轰宛平城、进攻卢沟桥。你是一名二十九军小兵，要守住桥头，
  击退日军三波进攻。

第二章  大刀 · 夜袭        1937.7.9 — 7.10
  铁路桥是卢沟桥的侧翼。二十九军组织大刀队夜袭，铁路桥一带反复易手。
  你跟随大刀队向铁路桥推进，摧毁两座机枪巢，在桥头竖起军旗。

第三章  南苑 · 最后一日    1937.7.28
  日军向南苑的二十九军军部与学兵团发起总攻。你被编入军部传令班，
  要守住撤退通道，掩护学兵团撤离。黄昏前撤出南苑。

【历史说明】
1937年7月7日夜，日军在北平西南卢沟桥附近演习，借口士兵失踪要求进入
宛平县城搜查，遭中国守军拒绝。7月8日拂晓，日军炮轰宛平城、进攻卢沟桥，
中国守军奋起抵抗，七七事变爆发，全民族抗战由此开始。

为符合真实背景，本作主角是二十九军三十七师一一〇旅二一九团三营的小兵，
不是八路军。1937年7月守卫卢沟桥的是国民革命军第二十九军；八路军于
1937年8月由红军主力改编成立，未参加7月的卢沟桥战斗。

本作没有血腥表现。谨以此纪念抗战先辈。
铭记历史，珍爱和平。

【战斗提示】
· 沙袋能挡住子弹。蹲在沙袋后更安全，但站起来才能看清桥面。
· 汉阳造是栓动步枪，每发之间需要拉栓；弹仓打空会自动装填。
· 近距离用大刀更有效，第二章的大刀队夜袭尤其适合近战。
· 击倒敌人有概率掉落弹药袋，走近自动拾取。
· 每章出生点附近有一个补给箱，可以补充一次体力和弹药。
· 敌人头顶的红色小三角是敌军识别标记，方便在夜色中分辨敌我。
· 生命值在脱离战斗一段时间后会缓慢恢复。

【难度】
  新兵：敌军火力较弱，体力上限更高，初始弹药更多。
  老兵：标准战场体验。
  血战：敌军更准、更疼、更快，体力上限更低。

【存档】
进度会自动保存在浏览器本地（localStorage）：每次开始一章会记录当前章节。
主菜单可以继续上次章节，也可以直接选择章节重玩。
“从第一章重新开始”会清除进度。
